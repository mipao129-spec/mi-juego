# Entre Páginas y Estrellas

Novela visual otome de estilo shōjo clásico, hecha con HTML, CSS y JavaScript puro.

## Incluye
- Pantalla inicial para introducir el nombre del jugador.
- El nombre se conserva durante la partida.
- Cuatro intereses románticos, todos adultos: Adrián (25), Dante (24), Elías (26) y Nicolás (23).
- Afinidad interna de -100 a 100, iniciada en 0 para cada personaje.
- Decisiones con consecuencias distintas según la personalidad.
- Indicadores de vínculo sin revelar números durante la partida.
- Etiquetas de música descriptivas al inicio de escenas importantes.
- Rutas y finales diferenciados.
- Ilustraciones SVG originales y no explícitas para los finales.

## Cómo jugar
Abre `index.html` en un navegador. No necesita servidor ni dependencias.
